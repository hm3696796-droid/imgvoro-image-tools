# ImgVoro - Private Image Utilities & View-Once Photo Sharing

[ImgVoro](https://imgvoro.com/) is a free, client-side image processing suite and ephemeral photo-sharing platform. All image processing runs locally in your browser using modern WebAssembly encoders.

## Core Online Tools
- 🌐 **Official Website:** [https://imgvoro.com](https://imgvoro.com/)
- 🔒 **View Once Photo Online:** [Single-View Ephemeral Image Link](https://imgvoro.com/one-time-view-image/)
- ⏳ **Self Destructing Photos:** [Expiring Image Links](https://imgvoro.com/self-destructing-image/)
- 🔑 **Password Protected Images:** [AES-256 Encrypted Links](https://imgvoro.com/password-protected-image/)
- ⚡ **Target Size Compressor:** [Compress Image to 200KB](https://imgvoro.com/compress-image-to-200kb/)
- ✂️ **Transparent Background Remover:** [Background Remover Online](https://imgvoro.com/background-remover-online)

## Privacy Architecture
- 100% Client-Side Processing: Photos are never stored on centralized servers.
- Automated EXIF Sanitization: GPS coordinates and metadata stripped automatically.
- Cloudflare Edge Purge: Expired temporary links permanently destroyed upon first view.
